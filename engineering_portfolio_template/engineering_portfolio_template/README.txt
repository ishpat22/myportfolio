ENGINEERING PORTFOLIO TEMPLATE

Files:
- index.html: portfolio content and structure
- style.css: visual styling and responsive layout
- images/: place your project photos, CAD renders, and simulation screenshots here

PREVIEW LOCALLY
1. Keep index.html, style.css, and the images folder together.
2. Open index.html in your browser, or use Live Server in VS Code.
3. Replace the placeholder text with your own details.
4. Add image files to images/ using the filenames shown in index.html:
   hero.jpg, project-01.jpg, project-02.jpg, project-03.jpg, project-04.jpg
   You can also change the src paths in index.html to match your filenames.

PUBLISH
Upload all files and the images folder to a static host such as GitHub Pages. Use relative paths like
images/project-01.jpg rather than a local path such as C:\Users\YourName\Desktop\image.jpg.

IMPORTANT
- Replace the sample metrics with verified results from your own work.
- Clearly distinguish simulation results from experimental validation.
- Only publish images and details you have permission to share; avoid confidential employer information.
